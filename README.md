# Tailhook Aces — 3D Naval Jet Fighter Simulator

A 3D browser-based naval aviation game featuring **Air-to-Air Wave Survival** dogfights and a **5-Stage Carrier Landing Challenge** ladder, built with Three.js and Vite.

## Quick Start (Local Development)

```bash
npm install
npm run dev
```

## Deploy to Firebase Hosting (`swifty`)

```bash
npm install
npm run deploy
```

## Flight Controls (Keyboard)

| Key | Action |
|---|---|
| `↑` / `↓` | Pitch Down / Pitch Up (`I` to toggle Flight-Stick / Direct pitch) |
| `←` / `→` | Roll Left / Roll Right |
| `W` / `S` | Throttle Up (Afterburner) / Throttle Down (Airbrake) |
| `A` / `D` | Rudder Yaw Left / Right |
| `SPACE` | 20mm M61 Vulcan Rotary Cannon |
| `F` | Fire AIM-9X Heat-Seeking Missile |
| `G` | Deploy Countermeasure Flares |
| `T` | Cycle Target Enemy |
| `L` | Toggle Landing Gear & Carrier Tailhook |
| `C` | Toggle 3rd-Person Chase / 1st-Person Cockpit HUD View |
| `H` | Toggle 3D Sky Glide-Slope Approach Boxes |
| `M` | Mute / Unmute Synthesized Audio & Radio Callouts |
